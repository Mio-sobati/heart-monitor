# 🩺 مانیتور هوشمند پزشکی پوشیدنی (ESP32-C3)

![Version](https://img.shields.io/badge/نسخه-28.0-blue.svg)
![Platform](https://img.shields.io/badge/پلتفرم-ESP32--C3-green.svg)
![UI](https://img.shields.io/badge/رابط_کاربری-Material_You_3-red.svg)

یک گجت پوشیدنیِ تجاری و متن‌باز (Open-Source) برای پایش لحظه‌ای علائم حیاتی، تشخیص هوشمند سقوط و ارسال هشدارهای پیامکیِ اضطراری (SOS). این سیستم بر پایه پردازنده ESP32-C3 توسعه یافته و دارای یک داشبورد وبِ اتوماتیک (Captive Portal) با طراحی مشابه iOS است.

## ✨ ویژگی‌های کلیدی

- **❤️ پایش ضربان قلب بافت عمیق:** تنظیمات فوق‌تخصصی سنسور `MAX30102` (فیلترهای ضد-اشباع نوری و ضد-پرش نبض) برای خوانش دقیق از روی ضخامت بازو و مچ.
- **🤸 تشخیص سقوط هوشمند:** استفاده از ماژول `GY-25` (MPU6050) با الگوریتم شتاب-دلتا و بررسی ۶ ثانیه‌ایِ سطح هوشیاری برای جلوگیری از هشدارهای کاذب.
- **😰 تشخیص حمله عصبی (Panic Attack):** پایش همزمان پرش‌های ناگهانی ضربان قلب و بی‌تحرکی بدن.
- **🚨 دکمه هوشمند چندمنظوره:** ۱ بار فشردن برای لغو آلارم و ۵ بار فشردنِ سریع برای ارسال پیامک دستی درخواست کمک (SOS).
- **📱 داشبورد Captive Portal:** بدون نیاز به نصب اپلیکیشن! فقط به وای‌فای گجت متصل شوید تا داشبورد پزشکی به صورت خودکار روی صفحه گوشی پاپ‌آپ شود (اندروید و iOS).
- **🎨 رابط کاربری زیبا:** سیستم دو زبانه (فارسی/انگلیسی)، حالت تاریک/روشن (Dark/Light Mode) و نوار ناوبری کپسولی.
- **✉️ هشدارهای پیامکی:** ارسال لحظه‌ای پیامک اورژانس با ذکر دقیق علت حادثه از طریق ماژول `SIM800C`.

## 🛠️ سخت‌افزار مورد نیاز

*   **میکروکنترلر:** ESP32-C3 Super Mini
*   **سنسور قلب و اکسیژن:** MAX30102 (ارتباط I2C)
*   **ژیروسکوپ:** GY-25 / MPU6050 (ارتباط Serial)
*   **ماژول مخابراتی:** SIM800C (ارتباط Serial)
*   **عملگرها:** بازر اکتیو (Buzzer) و موتور ویبره
*   **ورودی:** ۱ عدد تک‌سوییچ (Push Button)

## 🔌 راهنمای پین‌بندی (Pinout)

| قطعه | پین در (ESP32-C3) | توضیحات |
| :--- | :--- | :--- |
| **بازر (Buzzer)** | `GPIO 1` | Active LOW |
| **ویبراتور (Vibrator)** | `GPIO 21` | Active HIGH |
| **دکمه (Button)** | `GPIO 10` | INPUT_PULLUP |
| **سیم‌کارت SIM800 TX** | `GPIO 4` | اتصال به RX ماژول |
| **سیم‌کارت SIM800 RX** | `GPIO 5` | اتصال به TX ماژول |
| **ژیروسکوپ GY-25 TX** | `GPIO 2` | اتصال به RX ماژول |
| **ژیروسکوپ GY-25 RX** | `GPIO 3` | اتصال به TX ماژول |
| **سنسور MAX30102 SDA**| `GPIO 8` | دیتای I2C |
| **سنسور MAX30102 SCL**| `GPIO 9` | کلاک I2C |

## 🚀 راهنمای استفاده (نحوه اتصال)

۱. دستگاه را روشن کنید (اگر دکمه را هنگام روشن شدن نگه دارید، وارد حالت تنظیمات وای‌فای می‌شود).
۲. در گوشی خود وای‌فای را روشن کرده و به شبکه **Heart_Monitor** متصل شوید.
۳. *هیچ مرورگری را باز نکنید!* گوشی شما به طور خودکار داشبورد پزشکی را روی صفحه باز می‌کند.
۴. به تب **تنظیمات ⚙️** بروید و شماره موبایل اورژانس، رمز وای‌فای و حساسیت‌های پزشکی خود را تنظیم کنید.
